# Robin Solace — Portfolio

A responsive React + Vite portfolio for Robin Solace.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
Import this GitHub repository into Vercel and set the **Root Directory** to `robin-solace-portfolio`. Vercel will detect Vite automatically. Build command: `npm run build`; output directory: `dist`.

## Personalize
- Instagram link is set to https://www.instagram.com/robinsolace/
- Replace the sample Unsplash images and project titles in `src/main.jsx` with your own work.
- Add your real profile photo when ready.

This is an original portfolio implementation based on the project direction discussed; it is not a verified pixel-perfect copy of the reference website.
