# Robin Solace — Vercel website

This is a self-contained static website. No framework or environment variables are required.

## Deploy on Vercel
1. Import the GitHub repository `robinsolace/Robin` into Vercel.
2. In **Root Directory**, choose `vercel-site`.
3. Keep Framework Preset as **Other**.
4. Leave Build Command empty (or use the included default) and Output Directory as `.`.
5. Deploy.

## Profile photo
Add Robin's portrait to this folder and name it exactly `profile.jpg`. The website loads it from `./profile.jpg`.

## Edit
The site content and styles are in `index.html`. Instagram is linked to [@robinsolace](https://instagram.com/robinsolace).
